🚀 JAK ZACZĄĆ (3 OPCJE):

┌─ OPCJA 1: Najprościej (3 minuty)
│  chmod +x quickstart.sh
│  ./quickstart.sh
│  cp build/libs/autojoin-1.0.0.jar ~/.minecraft/mods/
│
├─ OPCJA 2: Klasycznie (5 minut)
│  chmod +x gradlew
│  ./gradlew build
│  cp build/libs/autojoin-1.0.0.jar ~/.minecraft/mods/
│
└─ OPCJA 3: Maven (alternatywa)
   mvn clean package
   cp target/autojoin-1.0.0.jar ~/.minecraft/mods/
